# 🖥️ Інструкція: Як створити Desktop версію BIZFLOW

## Варіант 1: Швидкий тест (для розробки)

Просто запустіть проєкт:
```powershell
dotnet run
```

Або подвійним кліком на файл: `start-desktop.ps1`

## Варіант 2: Створення EXE файлу для розповсюдження

### Крок 1: Відкрийте PowerShell в папці проєкту

### Крок 2: Запустіть скрипт публікації

```powershell
.\publish-desktop.ps1
```

Або вручну:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish/BIZFLOW-Windows
```

### Крок 3: Готово!

Файл `BIZFLOW.exe` буде в папці: `publish/BIZFLOW-Windows/`

## 📦 Що отримаєте?

- ✅ Один EXE файл `BIZFLOW.exe` (~70-90 MB)
- ✅ Не потребує встановлення .NET
- ✅ Працює на будь-якому Windows комп'ютері
- ✅ Автоматично відкриває браузер
- ✅ База даних SQLite створюється автоматично

## 🚀 Як користувач запускає додаток?

1. Скопіювати папку `BIZFLOW-Windows` на свій комп'ютер
2. Запустити `BIZFLOW.exe`
3. Автоматично відкриється браузер з інтерфейсом
4. Працювати як зазвичай!

## 📊 Розміри

- **EXE файл**: ~70-90 MB (включає .NET Runtime)
- **База даних**: стартує з 0, зростає з даними
- **Загалом**: ~100 MB на диску

## 🔐 Безпека даних

- Всі дані зберігаються локально на комп'ютері користувача
- Файл бази даних: `bizflow.db` (в папці з EXE)
- Для backup - просто скопіюйте `bizflow.db`

## 🌐 Мережа

- Працює тільки локально на комп'ютері користувача
- Адреса: `http://localhost:5555`
- Не потребує інтернету
- Не доступний з інших комп'ютерів (безпечно)

## ⚙️ Системні вимоги

- **ОС**: Windows 10/11 (x64)
- **RAM**: 512 MB мінімум
- **Диск**: 150 MB вільного місця
- **Процесор**: Будь-який сучасний x64

## 🎯 Порівняння підходів

| Характеристика | Desktop (поточний) | Веб-версія |
|----------------|-------------------|------------|
| Встановлення   | Просто EXE        | Потрібен сервер |
| Інтернет       | Не потрібен       | Потрібен |
| Розмір         | ~90 MB            | Залежить від сервера |
| Оновлення      | Нова версія EXE   | Автоматично |
| Дані           | Локально          | На сервері |
| Доступ         | Один комп'ютер    | З будь-якого місця |

## 💡 Поради

1. **Для тестування**: Використовуйте `dotnet run`
2. **Для розповсюдження**: Створіть EXE через `publish-desktop.ps1`
3. **Для оновлень**: Просто замініть EXE файл новою версією
4. **Для backup**: Зберігайте копію файлу `bizflow.db`

## ❓ Troubleshooting

**Проблема**: Браузер не відкривається автоматично
- **Рішення**: Відкрийте браузер вручну і перейдіть на `http://localhost:5555`

**Проблема**: Помилка "Address already in use"
- **Рішення**: Порт 5555 зайнятий. Змініть порт в Program.cs

**Проблема**: База даних не створюється
- **Рішення**: Переконайтеся, що у додатку є права на запис у папку
