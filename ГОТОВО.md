## 🚀 Як запустити зараз?

### Варіант 1: Подвійний клік
```
START-ELECTRON.bat   (подвійний клік у Провіднику)
```

### Варіант 2: Visual Studio
1. Відкрийте термінал у VS
2. Виконайте:
```bash
electronize start
```

### Варіант 3: Командний рядок
```bash
cd "D:\Diproject\BIZFLOW.Web"
electronize start
```

**⏱️ Перший запуск:** 2-5 хвилин (завантажить Electron ~150MB)  
**⚡ Наступні:** 20-30 секунд

## 📦 Як зібрати EXE для користувачів?

```bash
# Windows 64-bit інсталятор
electronize build /target win /electron-arch x64

# Результат:
# bin\Desktop\BIZFLOW Setup 1.0.0.exe (~150MB)
```

Віддайте цей EXE користувачам - вони запустять інсталятор і все! 🎉
