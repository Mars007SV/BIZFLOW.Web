# Історія операцій - Документація

## Огляд функціональності

Система історії операцій дозволяє відстежувати всі надходження та списання товарів у вашому складі.

## Основні можливості

### 1. Перегляд історії операцій
- Доступ: Меню "Історія операцій" або `/Operations`
- Показує всі операції з товарами
- Відображає дату, продукт, тип операції, кількість, залишок після операції

### 2. Фільтрація та пошук
Ви можете фільтрувати операції за:
- **Пошуковий запит**: назва продукту або опис операції
- **Тип операції**: Надходження або Списання
- **Діапазон дат**: від дати та до дати

### 3. Сортування
Натисніть на заголовок колонки для сортування:
- Дата операції
- Назва продукту
- Тип операції

### 4. Створення нової операції
1. Натисніть "Створити нову операцію"
2. Оберіть продукт зі списку
3. Вкажіть тип операції (Надходження/Списання)
4. Введіть кількість
5. За бажанням додайте опис
6. Система автоматично:
   - Запише дату та час операції
   - Оновить залишок товару
   - Збереже ім'я користувача
   - Збереже залишок після операції

### 5. Історія по конкретному продукту
- В списку продуктів натисніть посилання "Історія" біля потрібного продукту
- Переглядайте всі операції тільки з цим продуктом
- Бачте поточний залишок на складі

### 6. Деталі операції
- Повна інформація про операцію
- Дата та час до секунд
- Продукт та його категорія
- Тип операції з кольоровим індикатором
- Кількість зі знаком +/- 
- Залишок після операції
- Опис (якщо є)
- Користувач, який створив операцію

## Модель даних Operation

```csharp
- Id (int): Унікальний ідентифікатор
- ProductId (int): Зв'язок з продуктом
- Quantity (int): Кількість товару в операції
- Type (string): "Incoming" або "Outgoing"
- Date (DateTime): Дата та час операції
- Description (string, необов'язково): Опис операції до 500 символів
- UserName (string, необов'язково): Користувач, який виконав операцію
- RemainingQuantity (int): Залишок товару після операції
```

## Безпека та валідація

- Не можна списати більше товару, ніж є на складі
- Кількість повинна бути більше 0
- Всі обов'язкові поля перевіряються
- При створенні операції автоматично оновлюється кількість товару в Products

## Корисні поради

1. **Використовуйте опис**: Додавайте деталі про операцію (наприклад, "Повернення від клієнта", "Брак товару")
2. **Фільтруйте за датами**: Переглядайте операції за певний період
3. **Перевіряйте залишки**: В історії завжди видно залишок після кожної операції
4. **Історія продукту**: Швидко переглядайте всі рухи конкретного товару
