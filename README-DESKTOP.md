# README для Desktop версії BIZFLOW

## 🖥️ Desktop додаток BIZFLOW

Цей додаток працює як самостійна desktop програма на вашому комп'ютері.

### 📋 Що це означає?

- ✅ Не потрібен інтернет
- ✅ Всі дані зберігаються локально на вашому комп'ютері
- ✅ Додаток автоматично відкриває браузер при запуску
- ✅ База даних SQLite створюється автоматично

### 🚀 Як запустити?

1. Запустіть додаток подвійним кліком на `BIZFLOW.exe`
2. Додаток автоматично відкриє браузер з інтерфейсом
3. Працюйте з системою як зазвичай
4. Для завершення - закрийте вікно консолі або натисніть Ctrl+C

### 📦 Як створити Desktop версію для розповсюдження?

Запустіть скрипт у PowerShell:

```powershell
.\publish-desktop.ps1
```

Це створить папку `publish/BIZFLOW-Windows` з готовим додатком.

### 📁 Де зберігаються дані?

База даних SQLite створюється в папці з додатком:
- Файл: `bizflow.db`
- Автоматично створюється при першому запуску
- Всі ваші дані зберігаються локально

### 🔧 Технічні деталі

- Додаток запускається на порту: `http://localhost:5555`
- При запуску автоматично відкривається браузер
- Використовується вбудований веб-сервер Kestrel
- Не потребує встановлення .NET Runtime (self-contained)

### ⚠️ Важливо

- Не видаляйте файл `bizflow.db` - в ньому всі ваші дані
- Для резервного копіювання - скопіюйте файл `bizflow.db`
- Один екземпляр додатку на комп'ютер (порт 5555 не може бути зайнятий)

### 🆘 Підтримка

Якщо додаток не відкривається автоматично:
1. Відкрийте браузер вручну
2. Перейдіть на адресу: `http://localhost:5555`
