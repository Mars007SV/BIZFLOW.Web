## 🔐 Перший запуск

### Що ви побачите:
1. **Сторінка входу** з красивим дизайном (фіолетовий градієнт)
2. Дві опції:
   - Увійти (якщо вже є акаунт)
   - Зареєструватися (для нових користувачів)

### Створення першого користувача:

1️⃣ **Натисніть "Зареєструватися"**

2️⃣ **Заповніть форму:**
   - Ім'я користувача: `admin` (або будь-яке інше)
   - Пароль: `admin123` (мінімум 6 символів)
   - Підтвердження паролю: `admin123`
   - Повне ім'я: `Адміністратор` (необов'язково)

3️⃣ **Натисніть кнопку "Зареєструватися"**

4️⃣ **Готово!** Ви автоматично увійдете в систему

## 🐛 Можливі проблеми

### Проблема: Білий екран
**Рішення:**
```powershell
dotnet build
dotnet run
```

### Проблема: "Cannot access a disposed context"
**Рішення:**
```powershell
# Перезапустіть додаток
Ctrl+C
dotnet run
```

### Проблема: Міграції не застосовані
**Рішення:**
```powershell
dotnet ef database update
```

### Проблема: Помилка при створенні користувача
**Перевірте:**
1. Ім'я користувача унікальне (не існує)
2. Пароль не менше 6 символів
3. Паролі співпадають

## 📊 Статистика проєкту

### Файли системи авторизації:
- ✅ 2 контролери (Account, User)
- ✅ 1 сервіс (AuthService)
- ✅ 1 middleware (AuthenticationMiddleware)
- ✅ 2 моделі (User, AuthViewModels)
- ✅ 4 представлення (Login, Register, Profile, Index)
- ✅ 2 міграції (AddUserTable, UpdateUserTableForAuthentication)

### Загальна інформація:
- **Мова:** C# 13 (.NET 10)
- **База даних:** SQLite
- **Фреймворк:** ASP.NET Core MVC
- **Авторизація:** Session-based
- **Хешування:** SHA256
