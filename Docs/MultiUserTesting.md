# 🧪 Тестування багатокористувацької системи

## Сценарій тесту

### Крок 1: Перевірка шляху до даних
```powershell
# Запустіть і подивіться в консолі
dotnet run
```

**Очікуваний результат:**
```
📂 Директорія даних користувача: C:\Users\[ВашеІм'я]\AppData\Local\BIZFLOW
🗄️ База даних: C:\Users\[ВашеІм'я]\AppData\Local\BIZFLOW\bizflow.db
🔄 Перевірка та застосування міграцій...
✅ База даних готова!
```

---

### Крок 2: Створення даних для Користувача 1

1. **Увійдіть в Windows** під першим користувачем
2. **Запустіть** BIZFLOW
3. **Зареєструйтеся:**
   - Username: user1
   - Password: 123456
   - Full Name: Перший Користувач
4. **Додайте товар:**
   - Назва: "Товар користувача 1"
   - Категорія: "Тест"
   - Кількість: 10

---

### Крок 3: Перемикання на Користувача 2

#### Якщо є другий користувач Windows:

1. **Вийдіть** з Windows (Вихід / Switch User)
2. **Увійдіть** під другим користувачем Windows
3. **Запустіть** BIZFLOW
4. **Перевірте консоль** - шлях має бути інший:
   ```
   C:\Users\[ІншеІм'я]\AppData\Local\BIZFLOW\bizflow.db
   ```
5. **Зареєструйтеся:**
   - Username: user2
   - Password: 123456
   - Full Name: Другий Користувач
6. **Перевірте:** товарів немає (база порожня)
7. **Додайте товар:**
   - Назва: "Товар користувача 2"
   - Категорія: "Тест 2"
   - Кількість: 20

---

### Крок 4: Перевірка ізоляції

1. **Поверніться** до першого користувача Windows
2. **Запустіть** BIZFLOW
3. **Увійдіть** як user1
4. **Перевірте:**
   - ✅ Бачите "Товар користувача 1"
   - ❌ НЕ бачите "Товар користувача 2"

---

## 🔍 Ручна перевірка файлів

### Для користувача 1:
```powershell
# Відкрити папку з даними
explorer "$env:LOCALAPPDATA\BIZFLOW"

# Подивитися розмір бази
Get-Item "$env:LOCALAPPDATA\BIZFLOW\bizflow.db" | Select Name, Length
```

### Для користувача 2 (під іншим обліковим записом Windows):
```powershell
# Те саме, але шлях буде інший
explorer "$env:LOCALAPPDATA\BIZFLOW"
```

## ✅ Критерії успіху

- [x] У консолі відображається правильний шлях до даних
- [x] Створюється директорія `%LOCALAPPDATA%\BIZFLOW`
- [x] База даних створюється автоматично
- [x] Міграції застосовуються автоматично
- [x] Користувач 1 НЕ бачить дані Користувача 2
- [x] Користувач 2 НЕ бачить дані Користувача 1
- [x] Кожен може зареєструвати свого user1 (не конфліктує)

## 🐛 Можливі проблеми

### Проблема: "Cannot access the file because it is being used"
**Причина:** Додаток запущений під іншим користувачем Windows

**Рішення:**
1. Закрийте BIZFLOW у першого користувача
2. Або запускайте окремі інстанції (зміна порту)

### Проблема: Дані змішалися
**Перевірте:**
```powershell
# Під яким користувачем Windows ви зараз?
whoami

# Який шлях до бази використовується?
echo $env:LOCALAPPDATA\BIZFLOW
```
