┌───────────────────────────────────────────────────────────────┐
│  📦 ЯК СТВОРИТИ EXE ДЛЯ РОЗПОВСЮДЖЕННЯ?                       │
└───────────────────────────────────────────────────────────────┘

  1️⃣  Подвійний клік на файл: PUBLISH-DESKTOP.bat

  2️⃣  Зачекайте 1-2 хвилини (створюється EXE)

  3️⃣  Знайдіть папку: publish\BIZFLOW-Windows\

  4️⃣  Файл BIZFLOW.exe готовий! (~70-90 MB)

  5️⃣  Скопіюйте всю папку на інший комп'ютер

  6️⃣  Запустіть BIZFLOW.exe на іншому комп'ютері

  ───────────────
  • Visual Studio: натисніть F5
  • Командний рядок: dotnet run
  • PowerShell: .\start-desktop.ps1

  Публікація:
  ───────────
  • BAT: PUBLISH-DESKTOP.bat
  • PowerShell: .\publish-desktop.ps1
  • Вручну: dotnet publish -c Release -r win-x64 --self-contained
